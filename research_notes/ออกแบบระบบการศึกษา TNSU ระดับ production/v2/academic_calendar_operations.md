- ผู้บริหาร: dashboard deadline compliance ต่อวิทยาเขต (ส่งเกรดทัน %, ยืนยัน กยศ. %, OIT ครบ %)

**D. Data model hints** 🟡
- `AcademicCalendar(year, term, campus_scope, student_type, version, approved_by)` → `CalendarEvent(type, start, end, policy_ref)`; event types ใช้ enum ร่วมกันทั้ง 17 วิทยาเขต แต่วันที่ override ต่อวิทยาเขตได้
- แยก `TermModel` สองแบบ: Higher-Ed (ภาค 1/2/ฤดูร้อน, หน่วยกิต, GPA 0–4 + I/W/S/U) กับ Basic-Ed (ภาค 1/2, ผลการเรียน 8 ระดับ + ร/มส/ผ/มผ, ปพ.)
- `FinePolicy(type=daily|flat, amount, cap, count_holidays)`; `FeePolicy(cohort, program, campus, mode=flat|per_credit|mixed)`
- `CompetitionEvent` ↔ `Delegation` ↔ `LeaveRequest(bulk)` ↔ `MakeupExamRequest`
- `FiscalYear` แยกจาก `AcademicYear` และทุกรายการการเงินต้อง tag ทั้งสองค่า
