# One Platform UI — Naive UI + ธีม “Cobalt Slate”

## ทำไมเลือกแนวนี้ (สรุปจากการค้นคว้าเทรนด์ 2026)
- ระบบงานองค์กรปี 2026 เลิกใช้การ์ดขาวหนา ๆ เต็มจอ หันมาใช้กรอบน้อย ข้อมูลแน่นขึ้น และมีโหมดมืด (Linear เป็นตัวอย่างที่อ้างถึงบ่อย)
- โทนเย็น (น้ำเงิน–เทา) ล้าตาน้อยกว่าเมื่อใช้งานทั้งวัน · สีใช้บอกความหมาย ไม่ใช่ตกแต่ง — แดง/เขียว/เหลือง สงวนไว้สำหรับสถานะ
- เมนูและหน้าแรกต่างกันตามบทบาท (role-aware) และมีทางลัดค้นหา/สั่งงานด้วยคีย์บอร์ด

## สิ่งที่เปลี่ยนในระบบ
- **Shell ใหม่ (Naive UI):** NMenu แบ่งกลุ่มตามวงจรงาน ย่อเป็นแถบไอคอนได้ (จำค่าไว้) · บนมือถือเป็น NDrawer · แถบบนมี Breadcrumb, ปุ่มค้นหา, สลับธีม, กระดิ่ง (NBadge + NPopover), เมนูโปรไฟล์ (NDropdown: บทบาทเดโม, ธีม สว่าง/มืด/ตามระบบ, ออกจากระบบ)
- **Command palette (Ctrl/⌘ + K):** ค้นเมนู โครงการ และรหัสงาน (เช่น SPP-5) ตามสิทธิ์ของบทบาท ใช้คีย์บอร์ดได้ทั้งหมด
- **Feedback:** `notify()` แสดงผ่าน NMessage แยกประเภท สำเร็จ / เตือน (เช่น Workflow ไม่อนุญาต)
- **Dialog:** ทุก Dialog ใช้ NModal (Focus trap, Esc, ล็อกการเลื่อน) โดย API เดิมไม่เปลี่ยน
- **Project Register:** NDataTable เรียงลำดับทุกคอลัมน์หลัก กรองสถานะ/ทีมที่หัวตาราง แบ่งหน้า คลิกทั้งแถวเพื่อเปิดโครงการ
- **โหมดมืด:** ทุกหน้าใช้ CSS variable จากชุดเดียวกัน · ค่าเริ่มต้นตามระบบปฏิบัติการ

## แนวทางต่อ
หน้าที่ยังเป็น HTML เดิม (ฟอร์มลงทะเบียน, ตารางอื่น ๆ, Drawer ของงาน) ใช้ token เดียวกันอยู่แล้ว ทยอยย้ายไป NForm / NDataTable / NDrawer ได้ทีละหน้าโดยหน้าตาไม่กระโดด

## มาตรฐาน Usability ที่ใช้ทั้งระบบ (ปรับ 10 พ.ย. 2569)
| หัวข้อ | มาตรฐาน | ที่ทำในระบบ |
|---|---|---|
| ขนาดตัวอักษร | ใช้สเกลเดียว ไม่ต่ำกว่า 12px | 12 · 13 · 14 · 16 · 18 · 20 · 24 · 28 px (ตัดขนาดเศษ เช่น 11.5, 12.5, 13.5) |
| ความต่างสี (WCAG 2.2 AA) | ข้อความ ≥ 4.5:1 | สีข้อความรอง `muted` #5f6779 และ `faint` #717a8c บนพื้นขาว · โหมดมืดปรับคู่กัน |
