## M1 · Sales (SM) — Flow M1 · L1–L3

| ID | ฟีเจอร์ | ผู้ใช้ | ระบบทำอะไร | สถานะ |
|---|---|---|---|---|

| S-02 | Requirement Workspace (Overview · Process · บันทึกประชุมลูกค้า) | SM | เก็บเป็นเอกสารในโครงการ มีเวอร์ชัน | ✓ ทำแล้ว |

| S-04 | Checklist เอกสารที่ Forecast 70% (TOR Final · Cost Sheet · Quotation · Proposal) | SM | ไม่ให้ย้ายสถานะจนกว่าเอกสารครบ | ✓ ทำแล้ว |

| S-06 | Proposal จาก Template (Word Online) | SM | สร้างไฟล์ในโฟลเดอร์ Proposal | ✓ ทำแล้ว |
| S-07 | ติดตามประมูล: วันยื่น · วันประกาศผล · ราคาที่ยื่น | SM | ตรวจราคายื่น ≤ ราคาอนุมัติ · แจ้งเตือนก่อนวันประกาศ 1 วัน | ✓ ทำแล้ว |
| S-08 | ระยะอุทธรณ์ 7 วันทำการ | ระบบ | คำนวณจากปฏิทินราชการ ปิด Close Win ได้หลังพ้น | ✓ |
| S-09 | บันทึกผล Win / Lose | SM | Lose บังคับเหตุผล คู่แข่ง ราคา · หัวหน้าเปิดเป็นโครงการใหม่ได้ | ✓ |
| S-10 | หลัง Win: แจ้งทีมพัฒนา + ขอ PM | SM | แจ้ง PMO + หัวหน้า Dev ผ่าน Teams/อีเมล | ✓ ทำแล้ว |
| S-11 | Solution Catalog | SM / หัวหน้า | ทะเบียน Product ใช้ซ้ำ ดูยอดขายต่อ Product | ✓ ทำแล้ว |

**หน้าจอ:** Project Register · Opportunity Registration · หน้าโครงการ (แท็บ Requirement ★, เอกสาร, Cost Sheet, ประมูล) · Sales Pipeline · Sales Dashboard

**หน้าจอ:** Approval Requests · แท็บ Cost Sheet ในโครงการ · หน้าอนุมัติจากลิงก์อีเมล

## คำอธิบายฟีเจอร์ระยะหลัง
- **Solution Catalog** — ทะเบียน “สินค้า/โซลูชันสำเร็จรูป” ที่ทีมพัฒนาไว้แล้วนำไปขายซ้ำได้ (เช่น ระบบสารบรรณ, ระบบจองคิว) เก็บคำอธิบาย ราคาอ้างอิง Man-day มาตรฐาน Proposal ต้นแบบ และ Cost Sheet ตั้งต้น ตอนลงทะเบียนโครงการแบบ Product-led เลือกจาก Catalog แล้วได้เอกสารตั้งต้นทันที และดูได้ว่าแต่ละโซลูชันขายไปกี่โครงการ มูลค่าเท่าไร
- **My Performance** — หน้าของพนักงานแต่ละคน (เห็นเฉพาะตัวเองและหัวหน้า) สรุปชั่วโมงที่บันทึกรายวัน/รายเดือนเทียบ 8 ชม./วัน, OT ที่ขอและที่อนุมัติ, งานที่เสร็จตรงเวลา %, งานต่อโครงการ ใช้ตอบ Requirement TP-9 “ดู Performance ของตัวเองได้”
- **ปฏิทินกลาง** — ปฏิทินเดียวรวมทุกเหตุการณ์ที่มีวันที่: วันหยุดราชการ, การลา, นัดประชุม (Kick-off, Handover), วันส่งงวด, รอบ PM, วันประกาศผลประมูล, วันหมดประกัน กรองตามบทบาท/ทีม/โครงการ และ Sync ไป Outlook ได้
