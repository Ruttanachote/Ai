## รายการหน้า
| หน้า | เนื้อหา |
|---|---|
| L0-1 Context Diagram | ระบบกับผู้ใช้ 11 บทบาท ลูกค้า และ Microsoft 365 (Entra ID, SharePoint, Excel, Outlook, Teams) |
| L0-2 Process ภาพรวม | Cross-functional swimlane 1.0–10.0 ตั้งแต่ได้โอกาสขายจนต่อสัญญา MA |
| L0-3 สถานะโครงการ | วงจรสถานะ + บทบาทที่ย้ายได้ + เงื่อนไขก่อนย้าย |
| M1 Sales · L1 / L2 / L3 / Sequence | ลงทะเบียน → Requirement → ราคา → TOR → Forecast → ประมูล → ผล · กฎ requirementsFor · ประมูลภาครัฐและระยะอุทธรณ์ |
| M2 Approval · L1 / L2 / L3 / Sequence | อนุมัติราคา รอง → ผู้บริหาร ผ่านอีเมล · ตรวจไฟล์ถูกแก้ (Stale) · อายุ 60 วัน |
| M3 Handover · L1 / L2 / L3 / Sequence | Close Win → ขอ PM → PMO มอบหมาย → ประชุม 5 ฝ่าย · Handover gate · PO เทียบราคาอนุมัติ |
| M4 PM · L1 / L2 / L3 / Sequence | พื้นที่งาน → ทีม → Kick-off → งวดงาน → ติดตาม → ตรวจรับ → ส่งเข้าประกัน · รอบ Sprint · CR → งาน |
| M5 Team · L1 / L2 / L3 / Sequence | My Tasks → ย้ายสถานะ → บันทึกเวลา / OT · การลาและส่งต่องาน · canMove + Automation |
| M6 จัดซื้อ · L1 / L2 / Sequence | PR ในงบ Cost Sheet → OPN อนุมัติ · OT ในเงินกัน |
| M7 MA · L1 / L2 / L3 / Sequence | รับมอบเข้าประกัน → Preventive Maintenance → Service Desk → แจ้งต่อประกัน 3/1 เดือน → MA ปีถัดไป |
| ตรวจสอบความสอดคล้อง | ผลเทียบ Requirement กับ Flow และระบบ |

สัญลักษณ์: วงรีเขียว = เริ่ม · วงรีแดง = จบ · กล่องขาว = ผู้ใช้ทำ · กล่องฟ้า = ระบบทำ · ข้าวหลามตัด = ตัดสินใจ · กล่องม่วงเส้นประ = Microsoft 365 · กล่องเขียวขอบคู่ = Sub-process มีหน้าลงรายละเอียด · **กรอบแดงเส้นประ = To-be (ยังไม่มีในระบบ)**
