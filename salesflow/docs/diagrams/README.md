## รายการหน้า
| หน้า | เนื้อหา |
|---|---|

| M2 Approval · L1 / L2 / L3 / Sequence | อนุมัติราคา รอง → ผู้บริหาร ผ่านอีเมล · ตรวจไฟล์ถูกแก้ (Stale) · อายุ 60 วัน |

| M4 PM · L1 / L2 / L3 / Sequence | พื้นที่งาน → ทีม → Kick-off → งวดงาน → ติดตาม → ตรวจรับ → ส่งเข้าประกัน · รอบ Sprint · CR → งาน |

สัญลักษณ์: วงรีเขียว = เริ่ม · วงรีแดง = จบ · กล่องขาว = ผู้ใช้ทำ · กล่องฟ้า = ระบบทำ · ข้าวหลามตัด = ตัดสินใจ · กล่องม่วงเส้นประ = Microsoft 365 · กล่องเขียวขอบคู่ = Sub-process มีหน้าลงรายละเอียด · **กรอบแดงเส้นประ = To-be (ยังไม่มีในระบบ)**
