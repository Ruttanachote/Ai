# OKR Report — รายงานประชุม OKR ประจำเดือน

เมนู **Sales · ก่อนขาย → OKR Report** (`/reports/okr`) · ผู้บริหารเปิดจากเมนู Executive

| บทบาท | เห็นข้อมูล |
|---|---|
| SM | เฉพาะตัวเอง (โครงการที่ตัวเองเป็น SM) เทียบเป้าที่ตั้งใน SM Dashboard |
| หัวหน้ากลุ่ม | ทีมในกลุ่มตัวเอง — สลับดู "ตามทีม" หรือ "ตาม SM" |
| รองผู้บริหาร / ผู้บริหาร / Admin | ทุกทีม DT — สลับดูตามทีมหรือตาม SM |

## Objective และ Key Results

Objective: หาโครงการและปิดยอดขายให้ได้ตามเป้าปีนี้

| KR | วัดจาก | เป้า |
|---|---|---|
| KR1 ยอด Close Win สะสม | มูลค่าสัญญา (หรือราคาที่อนุมัติ) ของโครงการที่ได้งานในปีนี้ ถึงสิ้นเดือนที่เลือก | ยอดที่ควรถึงตามเวลา (เป้าทั้งปี × สัดส่วนวันที่ผ่านไป) |
| KR2 Coverage | Pipeline ถ่วงน้ำหนัก ÷ ยอดที่ยังขาด | ≥ 1.5 เท่า |
| KR3 โครงการใหม่ | Opportunity ที่ลงทะเบียนในเดือน | 2 โครงการ ต่อ SM ต่อเดือน |
| KR4 Win rate | ชนะ ÷ (ชนะ + แพ้) ปีนี้ | ≥ 40% |

สถานะ KR: บรรลุ (≥ 95% ของเป้า) · ใกล้เป้า (≥ 70%) · ต่ำกว่าเป้า
สถานะหน่วย: ตามเป้า / ต้องเร่ง (ยอด + Pipeline ถ่วงน้ำหนักยังพอ) / ต่ำกว่าเป้า — สูตรเดียวกับ Executive Dashboard
โครงการที่แบ่งยอดระหว่างทีมนับให้แต่ละทีมตามสัดส่วน · หน่วย SM นับเต็มมูลค่าของโครงการที่ตัวเองเป็น SM

## เนื้อหารายงาน

1. Objective + 4 KR · ยอดสะสมเทียบเป้าทั้งปี · Close Win รายเดือน
2. ผลรายทีม / ราย SM (เป้า, ยอดสะสม, % เป้า, เดือนนี้, ยังขาด, ถ่วงน้ำหนัก, Coverage, ใหม่, Win rate, สถานะ)
3. ความเคลื่อนไหวในเดือน (โครงการใหม่ เปลี่ยนสถานะ Close Win / Lose) จากประวัติสถานะ
4. คาดว่าจะปิดใน 3 เดือนข้างหน้า (จาก Expected Close) — ใช้เป็นแผนคุยในประชุมเดือนถัดไป
5. เหตุผลที่ไม่ได้งานปีนี้ และโครงการค้างนานเกินเกณฑ์ของสถานะ

## Export

- **Excel (.xlsx)** 5 ชีต: สรุป OKR · รายเดือน · ความเคลื่อนไหว · คาดปิด 3 เดือน · โครงการ — ตัวเลขเป็นตัวเลขจริง ช่อง % เป้า ยอดที่ขาด Coverage Win rate และแถวรวมเป็นสูตร Excel
- **PDF** A4 แนวนอน 3 หน้าขึ้นไป แสดงตัวอย่างก่อนดาวน์โหลด (วาดจากหน้าจอจึงแสดงภาษาไทยถูกต้อง)
