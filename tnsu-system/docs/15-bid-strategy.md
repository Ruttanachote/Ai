## 0. COI: ผู้ร่าง TOR อาจถูกห้ามเสนอราคา

- เอกสารชุดนี้เป็น **design ของผู้เสนองาน** และระบุชื่อผลิตภัณฑ์ ถ้า มกช. จะใช้ทำ TOR ต้องแปลงเป็น **brand-neutral capability spec** และ **แยกผู้ร่าง TOR** (คณะกรรมการของ มกช. หรือที่ปรึกษาที่ไม่ยื่นงานพัฒนา) โดยผู้ร่าง/กรรมการลงนาม **หนังสือแสดงความไม่มีส่วนได้เสีย** (พ.ร.บ.จัดซื้อฯ 2560 ม.13 🟡) — [เล่ม 10 หัวข้อ 11.1](10-security-compliance.md), blueprint ข้อ 9.11, [A-12], ทะเบียนความเสี่ยงเล่ม 12 **RK-09**
- **ผลต่อเรา:** ถ้าบริษัทหรือพันธมิตรใน consortium รับงานที่ปรึกษาเขียน TOR/ราคากลาง (pre-TOR consulting) มีโอกาสสูงที่จะ **ถูกห้ามยื่นงานพัฒนา** ✅ (หลักการที่บันทึกวิจัยระบุ; รายละเอียดเงื่อนไขต้องตรวจตามระเบียบที่ มกช. ใช้ — Q-85) **ต้องเลือกบทบาทเดียว** และเราเลือก **"ผู้เสนองาน"**
- **สิ่งที่ทำได้โดยไม่ขัด COI:** ส่งความเห็นผ่าน **การรับฟังความเห็นร่าง TOR สาธารณะ** (เช่น ข้อมูลราคาตลาดและความเสี่ยงของ scope); ตอบ RFI ที่ มกช. ส่งถึงผู้ประกอบการทุกรายเท่ากัน; นำเสนอเทคโนโลยีแบบเปิดต่อสาธารณะ — **ไม่ส่งเอกสาร design นี้ หรือส่วนใดของมัน ให้เป็นร่าง TOR**
- ภายในทีม: เก็บบันทึกการติดต่อกับ มกช. ทุกครั้ง (วันที่ ผู้เข้าร่วม หัวข้อ) และห้ามบุคลากรที่เคยเป็นกรรมการ/ที่ปรึกษาของ มกช. ในช่วงร่าง TOR เข้าทีมเสนองาน 🟡

| ประเด็น | สาระ |
|---|---|

### 11.3 วิธีคำนวณ NPV และ payback

- **สูตร:** NPV = Σ<sub>t=1..10</sub> (B<sub>full</sub> × ramp<sub>t</sub> − C<sub>t</sub>) ÷ (1 + r)<sup>t</sup>; r = 3% 🟡 (อัตราคิดลดภาครัฐที่สมมติ ต้องยืนยัน Q-89) [A-99]; horizon 10 ปีสัญญา (5 ปีโครงการ + 5 ปี run)
- **C<sub>t</sub>:** ปีสัญญา 1–5 จากเล่ม 12 หัวข้อ 6.4 (ต่ำ 42.03 / 57.66 / 58.43 / 52.80 / 37.31; สูง 64.83 / 91.05 / 95.72 / 87.48 / 64.24) และปี 6–10 = ค่า run 20.9 (ต่ำ) / 43.7 (สูง) ต่อปี
- **ramp<sub>t</sub>:** สัดส่วนผู้ใช้บนระบบใหม่ = 0, 0.05 (R1 รับสมัคร pilot), 0.18 (R2 pilot ≈ ผู้เรียน 2 วิทยาเขต), 0.55 (Wave 1 + โรงเรียนนำร่อง), 0.95 (Wave 2), 1.0 (ปี 6–10); Σ ramp ที่คิดลดแล้ว = 5.47
- **Payback** = ปีแรกที่ผลสะสม (B − C) เป็นบวก

| ผล (B<sub>full</sub> = 15.78 ล้าน/ปี) | กรณีต้นทุนต่ำ | กรณีต้นทุนสูง |
|---|---|---|
| PV ต้นทุน 10 ปี | 310.3 ล้าน | 542.1 ล้าน |
| PV ประโยชน์ 10 ปี | 15.78 × 5.47 = 86.3 ล้าน | 86.3 ล้าน |
| **NPV** | **≈ −224 ล้าน** | **≈ −456 ล้าน** |
| Payback | ไม่คืนทุนใน 10 ปี (ประโยชน์ 15.8 < ค่า run 20.9–43.7 ต่อปี) | ไม่คืนทุน |
| ประโยชน์ต่อปีที่ทำให้ NPV = 0 (break-even) | PV ต้นทุน ÷ 5.47 = **≈ 57 ล้าน/ปี** | **≈ 99 ล้าน/ปี** |

**การตีความที่ต้องเขียนตรง ๆ ใน proposal และเอกสารเสนอโครงการ:**

1. ในเชิงการเงินล้วน โครงการ **ไม่คืนทุน** ถ้านับเฉพาะประโยชน์ที่ระบุได้วันนี้ — ไม่ควรอ้าง ROI
2. กรณีเปรียบเทียบที่ถูกต้องไม่ใช่ "ไม่ทำอะไร = 0 บาท" แต่คือ **do-minimum**: ระบบเดิม 17+13 แห่งที่ต้องบำรุง/ปรับปรุงต่อ (เช่น มสธ. จ้างปรับปรุงเป็นรอบ ✅), การทำ ITA/PDPA/คุ้มครองเด็ก/รายงาน อว. ด้วยมือ และความเสี่ยงที่สะสม ค่า do-minimum ต้องวัดใน P0 (Q-87) แล้วคำนวณ **NPV ส่วนเพิ่ม** = NPV(โครงการ) − NPV(do-minimum)
3. ประโยชน์ที่ยังไม่ได้ตีเป็นเงิน: ความปลอดภัยของผู้เยาว์ 4,450 คน, ความเท่าเทียมของนักศึกษาต่างจังหวัด/นักกีฬาที่ไม่ต้องเดินทาง, ความโปร่งใสการคัดเลือก (score lock, OIT), ข้อมูลนักกีฬาตั้งแต่ ม.1 ถึงทีมชาติสำหรับนโยบายกีฬาชาติ (benchmark Top-15 #14), การรองรับการแยกกระทรวงโดยไม่ต้องแก้ระบบ
4. ทางเลือก B ลด break-even ลงตามสัดส่วนต้นทุน (≈ −23%) แต่ไม่เปลี่ยนข้อสรุป
5. ใช้ **cost-effectiveness** แทน ROI: ค่า run ≈ 1,248–2,609 บาท/ผู้เรียน/ปี (เล่ม 12) เทียบกับ SIS สากล ≈ $86–515/นศ./ปี (≈ 3,000–18,000 บาท 🟡) ✅ [VendorBenchmark](https://vendorbenchmark.com/guides/higher-education-software-pricing-benchmark)
